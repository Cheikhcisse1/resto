# Téranga Colobane : site du restaurant

## Installation
1. `npm install`
2. Créez un projet sur supabase.com, puis exécutez `supabase/schema.sql` dans le SQL Editor.
3. Copiez `.env.example` en `.env.local` et remplissez vos clés et votre numéro WhatsApp.
4. `npm run dev`, puis http://localhost:3000
5. Déploiement : importez le dépôt sur Vercel et ajoutez les mêmes variables d'environnement.

## À fournir par le restaurant (rien n'est inventé)
Adresse, téléphone, WhatsApp, horaires, réseaux sociaux, zones de livraison et frais, plats et prix (tables `categories`, `products`, `delivery_zones`, `settings`).
